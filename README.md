# devamittran-m.github.io

Personal portfolio of **Devamittran M**: data scientist, MBA at IIT Kanpur (2026 to 2028), and CFA Level I candidate, working across quant research, analytics, and AI engineering and policy.

🌐 **Live site:** [devamittran-m.github.io](https://devamittran-m.github.io)

## What's on the site
- An interactive Kalman filter playground on a simulated noisy price series
- Experience, projects and research, filterable by area (quant, analytics, AI)
- Honors, certifications and freelance services
- Light and dark themes, built to work on mobile

## How it's built
Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

| File | Purpose |
| --- | --- |
| `index.html` | Page content and SEO metadata |
| `style.css` | Layout, themes and components |
| `app.js` | Kalman filter playground, area filter, theme toggle, certificate viewer |
| `artifacts/` | Profile photo, certificates (originals) and `web/` resized copies |
| `sitemap.xml`, `robots.txt` | Search engine indexing |

## Updating
- **Photo:** replace `artifacts/profile.jpg` (square, about 800 × 800 px).
- **Resume:** upload `resume.pdf` to the repository root and the Download resume button turns on automatically.
- **Content:** edit `index.html`; changes go live within a minute or two of committing.
